Giải thích API  
1\. Prompt 3 phần  
\#\# Tôi là ai / Bối cảnh  
Tôi là thành viên mới nhóm SmartCampus (React Native).

\#\# Chủ đề / Nội dung cần xử lý  
Giải thích thuật ngữ "API" cho người mới bắt đầu.

\#\# Yêu cầu  
\- Dùng ví dụ người phục vụ nhà hàng để giải thích.  
\- Nêu vai trò của API trong app SmartCampus (gọi lấy lịch học).  
\- Dùng tiêu đề và danh sách gạch đầu dòng rõ ràng.

\#\# Không cần  
\- Không viết code backend phức tạp.  
\- Không đưa lý thuyết mạng hàn lâm.

2\. Tóm tắt câu trả lời (3 câu)  
API là cầu nối cho phép hai phần mềm trao đổi dữ liệu với nhau.  
Hoạt động giống như bồi bàn: nhận yêu cầu từ ứng dụng, gửi đến máy chủ xử lý rồi mang dữ liệu trả về màn hình.  
Trong SmartCampus, ứng dụng dùng API để lấy dữ liệu lịch học của sinh viên từ hệ thống trường.  
3\. Nội dung từ AI  
API là gì?  
API (Application Programming Interface) là giao diện cho phép các phần mềm giao tiếp với nhau.  
Ví dụ thực tế  
App mobile: Khách gọi món.  
Server trường: Nhà bếp nấu ăn.  
API: Người phục vụ chuyển order vào bếp và mang món ăn ra cho khách.  
Vai trò trong SmartCampus  
Ứng dụng gửi mã sinh viên qua API để lấy dữ liệu thời khóa biểu từ máy chủ trường về hiển thị.
